Gerenciamento de Bibliotecas e Módulos no Linux

1️⃣ Bibliotecas no Linux

As bibliotecas são pequenos trechos de código que podem ser reutilizados por programas, reduzindo o tamanho dos executáveis e otimizando o desempenho do sistema.

📌 Bibliotecas Compartilhadas
O Linux utiliza bibliotecas compartilhadas (.so - shared object) para evitar a necessidade de inclusão de código redundante em cada programa.

📌 Comandos para Gerenciar Bibliotecas

Comando	Descrição
ldd /bin/comando	Exibe as bibliotecas utilizadas por um programa.
ldconfig -p	Lista o cache dos caminhos das bibliotecas disponíveis.

Se uma biblioteca não for encontrada, o comando ldd retorna “not found”, indicando que a dependência está ausente.

📌 Adicionando um Novo Diretório de Bibliotecas
	1.	Criar um diretório para armazenar as bibliotecas:

mkdir /bibliotecas


	2.	Criar um arquivo de configuração no /etc/ld.so.conf.d/:

cd /etc/ld.so.conf.d/
vim bibliotecas.conf  # O arquivo deve ter a extensão .conf


	3.	Dentro do arquivo bibliotecas.conf, adicionar o caminho do diretório:

/bibliotecas


	4.	Atualizar o cache das bibliotecas:

ldconfig



📌 Definindo um Caminho Temporário para Bibliotecas

Podemos definir um caminho temporário para uma biblioteca utilizando a variável de ambiente LD_LIBRARY_PATH:

export LD_LIBRARY_PATH=/opt

⚠️ Importante: Essa configuração não é persistente, ou seja, será perdida após o reboot.

2️⃣ Módulos do Kernel

O Kernel é o núcleo do sistema operacional, responsável por gerenciar hardware e recursos do sistema.
Ele pode ser estendido através de módulos, que são pequenos arquivos carregados dinamicamente para adicionar funcionalidades.

📌 Os módulos do Kernel geralmente possuem a extensão .ko (Kernel Object).
📌 O Kernel e seus módulos estão localizados em /lib/modules/versao_do_kernel/

📌 Principais Comandos para Gerenciar Módulos do Kernel

Comando	Descrição
lspci -k	Lista todos os dispositivos PCI e os módulos do Kernel associados.
lsmod	Lista todos os módulos carregados no momento.
`lsmod	wc -l`
modinfo modulo	Exibe informações detalhadas sobre um módulo.
rmmod modulo	Remove um módulo carregado.
depmod	Faz uma varredura nos módulos .ko e gera o cache em /lib/modules/versao_kernel/modules.dep.

📌 Carregando Módulos no Kernel

Existem duas formas de carregar um módulo:

1️⃣ Carregamento direto (não recomendado):

insmod /caminho_completo/modulo.ko

⚠️ O insmod não resolve dependências, então pode falhar caso um módulo dependa de outro.

2️⃣ Carregamento via modprobe (recomendado):

modprobe nome_do_modulo

Exemplo: sudo modprobe usblc

O modprobe carrega o módulo e suas dependências automaticamente, utilizando as informações de /lib/modules/versao_kernel/modules.dep.

📌 Como os Módulos São Carregados na Inicialização?

Os módulos são carregados dinamicamente com base no hardware detectado pelo Kernel. O carregamento pode ser configurado manualmente através de arquivos em /etc/modules-load.d/.
