Gerenciador de Pacotes no Debian

O Debian utiliza dois tipos de gerenciadores de pacotes:
	•	Alto nível: Gerencia pacotes e dependências automaticamente, utilizando repositórios. (APT)
	•	Baixo nível: Trabalha diretamente com pacotes .deb, sem resolver dependências automaticamente. (DPKG)

1️⃣ Gerenciador APT (Advanced Package Tool)

O APT gerencia pacotes a partir dos repositórios configurados em:
📌 Arquivo de repositórios: /etc/apt/sources.list
?≥📌 Tipos de repositórios:
	•	deb https://... → Pacotes pré-compilados (.deb).
	•	deb-src https://... → Código fonte dos pacotes.

💡 As distribuições Debian são nomeadas com referências ao filme Toy Story (ex.: Jessie, Buster, Bullseye).

📌 Principais comandos do APT

Comando	Descrição
apt update	Atualiza a lista de pacotes disponíveis nos repositórios.
apt list --upgradable	Lista pacotes que possuem atualizações pendentes.
apt list	Lista todos os pacotes instalados no sistema.
apt upgrade	Atualiza todos os pacotes do sistema.
apt show pacote	Exibe informações detalhadas sobre um pacote (descrição, dependências, etc.).
apt search termo	Pesquisa pacotes relacionados a um termo específico. Exemplo: apt search network.
apt install pacote1 pacote2 -y	Instala um ou mais pacotes.
apt remove pacote	Remove um pacote, mas mantém as dependências e arquivos de configuração.
apt remove --purge pacote	Remove um pacote e todos os arquivos de configuração.
apt download pacote	Baixa um pacote .deb, sem instalá-lo.
apt clean	Limpa arquivos de cache do APT.



⸻

2️⃣ Instalação a partir do Código Fonte

Caso um pacote não esteja disponível no repositório oficial, ele pode ser compilado manualmente:

cd /opt
apt source pacote          # Baixa o código-fonte do pacote
cd pacote_codigo_fonte     # Entra no diretório do código-fonte
apt build-dep pacote       # Instala as dependências necessárias
./configure                # Configura a compilação
make                       # Compila o programa
make check                 # Verifica se há erros
make install               # Instala o programa no sistema

Após a instalação, o programa pode ser utilizado normalmente.

⸻

3️⃣ Gerenciador DPKG (Debian Package Manager)

O dpkg gerencia pacotes .deb diretamente, sem resolver dependências.

📌 Principais comandos do DPKG

Comando	Descrição
dpkg -l pacote	Verifica se um pacote está instalado.
dpkg -la	Lista todos os pacotes instalados.
dpkg -i pacote.deb	Instala um pacote .deb manualmente.
dpkg -L pacote	Lista os arquivos pertencentes a um pacote e suas localizações.
dpkg -s pacote	Mostra o status detalhado de um pacote.
dpkg -r pacote	Remove um pacote, mas mantém os arquivos de configuração.
dpkg -C	Verifica problemas de integridade nos pacotes instalados.
dpkg -S /bin/arquivo	Descobre a qual pacote pertence um determinado arquivo binário.



⸻

4️⃣ Conversão de Pacotes (.rpm ⇄ .deb)

O CentOS e Fedora utilizam pacotes no formato .rpm, enquanto o Debian e Ubuntu utilizam .deb.
Em alguns casos, é possível converter pacotes entre os formatos com a ferramenta Alien:

📌 Instalar e usar o Alien

apt install alien build-essential -y   # Instala o conversor Alien
alien -r pacote.deb                    # Converte .deb para .rpm
alien -d pacote.rpm                     # Converte .rpm para .deb

⚠️ Atenção: A conversão pode gerar problemas de compatibilidade, principalmente em pacotes mais complexos.
