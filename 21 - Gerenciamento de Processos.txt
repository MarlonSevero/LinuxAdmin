# Gerenciamento de Processos no Linux

## Conceito de Processos
Processos são eventos internos do sistema operacional que representam a execução de programas.

### Informações de um Processo
Cada processo possui atributos importantes, como:
- **Quem iniciou**
- **PID** (Process Identification)
- **Terminal associado**
- **Uso de processamento e memória**
- **Estado**

## Systemd
O **Systemd** é o principal processo em execução no Linux, responsável por iniciar e gerenciar outros processos do sistema.

---
## Comandos para Gerenciar Processos

### `ps` - Listagem de Processos
Exibe informações sobre processos em execução.

- `ps -aux` → Lista todos os processos ativos.

Formato da saída:
```
USER   PID  %CPU  %MEM  VSZ   RSS   TTY  STAT  START  TIME  COMMAND
```
- `Ss` - **Sleeping** (Parado)
- `Rr` - **Running** (Em execução)

Outros usos:
- `ls /proc` → Exibe diretórios que armazenam informações sobre processos.
- `ps -aux | more` → Exibe os processos de forma paginada.
- `ps -aux | grep bash` → Filtra processos, neste caso, mostrando apenas processos relacionados ao `bash`.
- `man ps` → Manual com diversos exemplos, como:
  - `ps axjf` → Exibe processos em formato de árvore.
  - `ps -u usuarioX` → Lista processos de um usuário específico.

### `pgrep` - Buscar Processos
- `pgrep -a bash` → Lista processos filtrando pelo nome.
- `pstree -p` → Exibe processos em formato de árvore, facilitando a visualização da hierarquia.

### `pidof` - Obter PID de um Processo
- `pidof top` → Retorna o ID do processo `top`.

---
## Monitoramento Interativo

### `top` e `htop`
Ferramentas interativas para monitoramento de processos em tempo real.

Atalhos úteis:
- `D` → Altera o tempo de atualização.
- `P` → Ordena por uso de CPU.
- `M` → Ordena por uso de memória.
- `>` / `<` → Navega entre processos.
- `L` → Pesquisa um processo.
- `Z` → Altera cores da interface.
- `k` → Finaliza um processo informando seu PID.

---
## Finalização de Processos

### `kill` - Envio de Sinais para Processos
- `kill -l` → Lista os sinais disponíveis.
- Sinais mais usados:
  - `15 (SIGTERM)` → Finaliza o processo de forma segura (padrão).
  - `09 (SIGKILL)` → Mata o processo imediatamente.
  - `03 (SIGQUIT)` → Sai do processo (equivalente a `Ctrl + C`).

Exemplo:
```bash
pidof top
kill -9 19551  # Mata o processo com PID 19551
kill -19 19551 # Pausa o processo
kill -18 19551 # Retoma o processo
```

### `pkill` e `killall`
- `pkill -9 top` → Mata todos os processos com nome `top`.
- `killall -9 top` → Mata todos os processos com nome `top`.

## Execução em Segundo Plano

Se estiver editando um arquivo no `vim` e precisar suspender a execução:
- `Ctrl + Z` → Suspende a tarefa.
- `jobs` → Lista os processos em segundo plano.
- `fg 1` → Retoma o primeiro processo suspenso.
- `fg %2` → Retoma o segundo processo suspenso.

### `nohup` - Manter um Processo Ativo Mesmo Após Fechar o Terminal
```bash
nohup ping -c 200 192.168.0.1 &
tail -f nohup.out  # Verifica a saída do processo
```

## Controle de Prioridade

### `nice` - Definir Prioridade ao Iniciar um Processo
- `-20` → Prioridade alta.
- `0` → Prioridade normal.
- `19` → Prioridade baixa.

Exemplo:
```bash
nice -n -20 vim doc.txt  # Inicia o Vim com prioridade alta
```

### `renice` - Alterar Prioridade de um Processo em Execução
```bash
pidof vim
renice -n 20 -p 19856  # Altera a prioridade do processo 19856
```

---
## Conclusão
O gerenciamento de processos no Linux é fundamental para a administração de sistemas, permitindo monitorar, finalizar e ajustar a prioridade de execução conforme necessário.
