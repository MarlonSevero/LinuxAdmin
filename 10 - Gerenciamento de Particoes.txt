📌 Gerenciamento de Partições e Sistemas de Arquivos no Linux

1️⃣ Criando Partições

Comando principal: fdisk /dev/sdX
	1.	Selecionar o disco: fdisk /dev/sdb
	2.	Exibir opções: Digitar m
	3.	Verificar espaço não alocado: F
	4.	Criar nova partição: n
	5.	Escolher tipo de partição (primária ou estendida).
	6.	Definir numeração da partição (padrão).
	7.	Selecionar quantidade de setores (padrão).
	8.	Definir tamanho da partição: +4G (exemplo).
	9.	Exibir partições criadas: p
	10.	Salvar alterações e sair: w

⸻

2️⃣ Formatando a Partição

Comando principal: mkfs -t [sistema_de_arquivos] /dev/sdXn

🔹 Criando uma partição XFS:
	•	Definir o sistema de arquivos:

mkfs -t xfs /dev/sdb1

⚠️ No Debian, pode ser necessário instalar o XFS:

apt install xfsprogs -y


	•	Definir um rótulo para o sistema de arquivos:

xfs_admin -L express /dev/sdb1



🔹 Criando uma partição EXT4/EXT3:
	•	Formatar com EXT4:

mkfs -t ext4 /dev/sdb1


	•	Definir um rótulo:

tune2fs -L meu_label /dev/sdb1



⸻

3️⃣ Montando a Partição

Comando principal: mount [dispositivo] [diretório]
	1.	Criar um diretório para montagem:

mkdir -p /srv/www/express/


	2.	Montar a partição:

mount /dev/sdb1 /srv/www/express/


	3.	Adicionar no /etc/fstab para montagem automática:

vim /etc/fstab

	•	Para XFS:

/dev/sdb1 /srv/www/express xfs defaults 0 0


	•	Para EXT4:

/dev/sdb1 /srv/www/express ext4 defaults 0 0


	•	Alternativamente, usando LABEL:

LABEL=logs /var/log/apache2 xfs defaults 0 0


	4.	Aplicar a montagem automática:

mount -a



⸻

🔄 Migração de EXT3 para EXT4
	1.	Checar integridade e salvar hash:

sha1sum /etc/*.conf > /etc/conf.sha1sum
tar -cvf /backups/conf.tar /etc/


	2.	Sair do diretório raiz:

cd /


	3.	Desmontar o dispositivo:

umount /backup


	4.	Verificar desmontagem:

df -h


	5.	Aplicar recursos do EXT4:

tune2fs -O extents,uninit_bg,dir_index /dev/sdb2


	6.	Atualizar /etc/fstab:

vim /etc/fstab

	•	Alterar ext3 para ext4.

	7.	Montar novamente:

mount -a


	8.	Validar integridade dos arquivos:

sha1sum -c /etc/conf.sha1sum



⸻

✔️ Este guia fornece um fluxo claro para gerenciar partições, formatá-las e montá-las no Linux. 🚀
